# Streamlined Automated Workflow Plan

## Goal
Transform the bot from an interactive conversational assistant into a fully automated pipeline. It will receive an input (text/URL and optional image), process it into a news post, render the image, and post it to Buffer without requiring any user interaction or confirmation buttons. 

## Steps

### 1. Database and Dependency Removal
- **Files to Delete:**
  - `src/db/schema.ts`
  - `src/db/index.ts`
  - `drizzle.config.ts`
  - The entire `src/db` directory.
- **Dependencies to Remove:**
  - `drizzle-orm`, `drizzle-kit`, `pg`, `@types/pg` from `package.json`.

### 2. Refactoring `src/bot.ts`
- Remove all database imports, chat history saving/fetching, and the `/clear` command.
- Remove inline keyboard callback actions (`publish_to_buffer` and `cancel_publish`).
- Update the message handlers (`text` and `photo`) to extract the user's text and optional image URL, then immediately call a new streamlined function `runAutomatedPipeline(ctx, text, photoUrl)`.
- The bot will send sequential status updates (e.g., "🔍 Mencari informasi...", "✍️ Menyusun konten...", "🚀 Mempublikasikan...") instead of waiting for input.

### 3. Implementing the Automated Pipeline (`src/agent.ts`)
Replace `processConversationalRequest` with a new `runAutomatedPipeline(ctx, text, uploadedImageUrl)` function. The pipeline consists of 5 distinct phases:

**Phase 1: Research (Fact Gathering)**
- Use `generateText` with the `ai` SDK.
- Enable `searchWeb` and `scrapeUrl` tools with `maxSteps: 3` so the AI can autonomously search or scrape the provided topic/URL.
- System prompt instructs the AI to summarize all relevant facts into a comprehensive text block.

**Phase 2: Content Generation**
- Use `generateObject` with a strict `zod` schema to parse the gathered facts into the final components:
  - `title` (string)
  - `subtitle` (string)
  - `source_name` (string)
  - `caption_body` (string) - 2 paragraphs, formatted according to the specific tone and ideological guidelines.
  - `image_prompt` (string) - Used if no image was uploaded.

**Phase 3: Image Sourcing (Standard Control Flow, NOT a tool)**
- If the user provided an image (`uploadedImageUrl`), skip generation and use it directly.
- If no image was provided, programmatically execute `generateText` with the `gemini-3.1-flash-image-preview` model using the `image_prompt` generated in Phase 2. This completely removes the image generator from the AI's "tools" array.
- Send this generated image to Telegram momentarily to get a public `fileLink` URL (required by the rendering API).

**Phase 4: Image Rendering**
- Call the existing `generateNewsImage` API (`src/image.ts`) with the text components (title, subtitle, source, date) and the base image URL.
- Receive the final rendered news image as a Buffer.

**Phase 5: Publishing via Buffer**
- Send the final rendered Buffer to the user via Telegram as a photo with the `caption_body`. This acts as a receipt and hosts the image.
- Extract the Telegram `fileLink` of this final image.
- Pass the `fileLink` and `caption_body` to `publishToBuffer` (`src/buffer.ts`).
- Send a final "✅ Berhasil dipublikasikan ke Buffer" message.

### 4. Code Cleanup
- Clean up unused imports across all files.
- Ensure error handling is robust at each phase of the pipeline so the user is informed if a specific step (e.g., search or publishing) fails.

### 5. Instagram Carousel Support (Multi-Image Forwarding)
To support Instagram carousel posts when users forward multiple images (a media group/album) from Telegram:
- **`bot.ts`**: Update the photo handler to accumulate incoming photos belonging to the same `media_group_id`. Wait for a brief timeout (e.g. 2000ms) after the first photo to capture all slides in the album. Pass an array of `imageUrls` and the overall caption to the agent pipeline.
- **`agent.ts`**: Change the pipeline to accept `uploadedImageUrls: string[]`. Use the first item (`uploadedImageUrls[0]`) as the cover image that goes through Phase 3 and 4 (Image Rendering). Combine the rendered cover URL with the rest of the unmodified image URLs: `[renderedCoverUrl, ...uploadedImageUrls.slice(1)]`.
- **`buffer.ts`**: Update `publishToBuffer` to accept an array of URLs. Dynamically construct the GraphQL `assets` input list so each URL is mapped to an `{ image: { url: "..." } }` object to create an Instagram carousel post.
